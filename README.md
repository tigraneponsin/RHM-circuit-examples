# RHM-circuit-examples
This repository contains examples of circuit tracing using Sparse Autoencoders, for Transformers trained on classification for the Random Hierarchy Model.

Interactive attribution graphs for transformers trained on the Random Hierarchy Model, generated by the circuit-tracing pipeline of [SAE-on-RHM](https://github.com/tigraneponsin/SAE-on-RHM).

- **Browse:** https://tigraneponsin.github.io/RHM-circuit-examples/
- **Code:** [SAE-on-RHM](https://github.com/tigraneponsin/SAE-on-RHM) (`scripts/circuit_tracing/`)
- **Report:** [PDF](https://github.com/tigraneponsin/SAE-on-RHM/blob/main/Report_EPFL.pdf), Section 5
